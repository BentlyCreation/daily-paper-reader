## 摘要
周围智能体的精确运动预测与安全运动规划是拥挤环境中社交机器人导航的两个紧密耦合的关键任务。将这些系统部署在资源受限的边缘设备上，需要紧凑、统一的模型来同时执行这两项任务。然而，在紧凑的共享编码器中，近期统一模型常常忽视了由于预测邻居行为与自我中心安全规划的不同目标引发的严重表征冲突。为解决此问题，我们首先识别出“技能冲突”——一种由参数重叠分配导致不同任务争夺相同权重，从而阻止模型完全专注于单个技能的现象。为化解这一冲突，我们提出一种基于模型合并的新框架：分离参数训练（DPT）。DPT通过分布式参数学习减轻技能冲突导致的性能退化，在合并前分离每个任务的关键参数区域，同时保留其核心能力。此外，我们观察到稀疏合并（即仅选择性整合每个任务最有影响力的参数，而非合并所有任务特定参数）可通过防止相邻特征干扰并集中表征能力，实现最优性能。DPT可与多种合并方法并行应用。在标准人群导航基准（JRDB和JTA）上的评估表明，我们的框架展现出优越性能，验证了其在安全、资源高效的机器人导航中的通用性与有效性。

## Abstract
Accurate motion prediction of surrounding agents and safe motion planning are two closely coupled key tasks for social robot navigation in crowded environments. Deploying these systems on resource-constrained edge devices necessitates compact, unified models that can perform both tasks simultaneously. However, within these compact shared encoders, recent unified models often overlook severe representational conflicts that arise from the distinct objectives of predicting neighbor behaviors versus ego-centric safety planning. To address this issue, we first identify the Skill Conflict$\unicode{x2014}$a phenomenon where overlapping parameter assignments cause distinct tasks to compete for the same weights, preventing the model from fully specializing in individual skills. To resolve this, we propose a novel model-merging-based framework, Disjoint Parameter Training (DPT). DPT mitigates performance degradation caused by Skill Conflict through distributed parameter learning, which separates the key parameter regions of each task while preserving their core capabilities prior to merging. In addition, we observe that sparse merging, which selectively integrates only the most influential parameters for each task rather than combining all task-specific parameters, yields optimal performance by preventing interference among adjacent features and concentrating representational capacity. DPT can be applied in parallel with a variety of merging methods. Evaluated on standard crowd navigation benchmarks (JRDB and JTA), our framework demonstrates superior performance, validating its versatility and effectiveness for safe, resource-efficient robot navigation.

## 1. 核心问题与整体含义（研究动机和背景）

在拥挤环境中，社交机器人导航需要同时执行两个紧密耦合的任务：准确预测周围智能体的未来轨迹（运动预测），以及基于这些预测生成自身安全、合规的轨迹（运动规划）。为了在资源受限的边缘设备上部署，通常采用紧凑的统一模型，使用共享编码器同时处理两个任务。然而，预测任务需要关注邻居行为的多样性与意图，而规划任务需要关注自车安全与可行性，两者的目标差异导致共享编码器中产生严重的表征冲突，这种现象被称为 **“技能冲突”（Skill Conflict）**——即不同任务因参数区域重叠而竞争同一组权重，导致模型无法充分专精于单个技能。现有统一模型大多忽略此问题，或依赖大规模模型容量来缓解，但边缘设备上的紧凑模型容量有限，冲突尤为致命。本文旨在解决这一根本问题。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
通过 **模型合并（Model Merging）** 的视角，提出 **分离参数训练（Disjoint Parameter Training, DPT）** 框架，在合并之前将预测和规划任务的核心参数区域分离，避免参数重叠。随后采用 **稀疏合并（Sparse Merging）** 仅整合每个任务最有影响力的任务向量，进一步减少相邻特征间的干扰。

### 关键技术细节
- **任务向量（Task Vector）**：对每个任务独立微调，得到模型参数变化量：  
  τ_t = Θ_t - Θ_0 （t ∈ {pred, plan}）。
- **技能冲突的定义与度量**：使用二值激活掩码 M_t(K) 选择每个任务向量中绝对值最大的 top-K% 参数，定义重叠度为两个掩码共享参数的比例。实验表明，随着K增大，重叠急剧上升（如10%掩码时重叠8.35%，50%时达39.25%），导致联合任务性能饱和。
- **DPT训练流程**（算法1）：
  1. 初始化所有任务掩码为零，模型从预训练权重Θ0开始。
  2. 前一半训练轮次：交替处理plan和pred任务。对于每个任务，计算梯度，从未被任何任务占用的参数中选择梯度绝对值最大的K个参数，为其分配掩码并更新这些参数。
  3. 后一半训练轮次：固定掩码，只更新已分配的参数区域。从而生成两个任务各自的核心参数互不相交的微调模型 f_plan 和 f_pred。
- **稀疏合并**：合并时仅整合每个任务向量中贡献最大的极小部分（例如 top 1% 的坐标），即：
  Θ_merged = Θ_0 + M_pred(K%) ⊙ τ_pred + M_plan(K%) ⊙ τ_plan。  
  这样做可避免即使主要参数区域不重叠、但相邻坐标仍可能产生功能性干扰的问题。
- **联合推理增强（Joint Reasoning, JR）**：在DPT+稀疏合并后，额外在剩余未激活参数上微调联合损失，以恢复统一模型中跨任务协同推理的优势。

## 6. 主要结论与发现

1. **技能冲突真实存在且在紧凑统一模型中严重**：参数重叠率随利用率上升而急剧增加，导致联合任务性能饱和。
2. **DPT有效分离任务核心参数区域**：通过交替梯度选择并固定掩码，可使预测与规划任务的核心参数互不相交，从根源上消除参数级冲突。
3. **稀疏合并优于全合并**：仅使用top 1%~2%任务向量即可达到最优性能，避免相邻特征干扰。
4. **DPT可即插即用于多种合并方法**：无论线性合并（Task Arithmetic）、符号冲突解决（Ties Merging）还是稀疏掩码（Localize-and-Stitch），DPT作为微调预处理均能提升最终融合性能。
5. **联合推理仍有价值**：在DPT+SM基础上，在未分配参数上加入联合微调可进一步提升性能（表4最后一列）。
6. **方法在端到端驾驶场景同样有效**：将感知与规划分组应用DPT，在HiP-AD上提升闭环比Open-loop指标。

## 8. 不足与局限

- **超参数敏感性**：DPT的关键超参数（任务分配比例、掩码增长率K、总掩码大小）需要手动设定，文中虽提供敏感性分析，但未给出自适应选择机制。
- **仅限两个主要任务**：方法主要针对预测与规划两个任务；扩展至更多任务（如感知+预测+规划）可能需要更复杂的任务分组策略，文中仅在补充实验中初步尝试3-way DPT并发现性能下降。
- **训练成本增加**：相比常规联合训练或直接微调，DPT需要额外交替训练和掩码管理，GPU小时数增加约1.2~1.5倍（但仍属可接受范围）。
- **数据集局限性**：JRDB和JTA均为人-机器人交互场景，未在例如Waymo、nuScenes等更大规模自动驾驶数据集上验证（补充实验使用了Bench2Drive自动驾驶数据集，但限于HiP-AD单一主干）。
- **未在真实机器人上部署验证**：所有实验均为离线评测，缺少实际边缘设备延时、功耗、稳定性测试。
- **依赖预训练模型**：DPT从已进行游戏论联合预训练的模型开始，预训练质量对最终性能有影响；若预训练效果不佳，DPT可能会继承偏差。
- **合并后联合推理机制简单**：额外JR微调仅在未激活参数上训练，未探索更复杂的容量分配方案。
