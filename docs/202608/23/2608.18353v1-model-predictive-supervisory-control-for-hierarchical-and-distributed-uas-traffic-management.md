## 摘要
本文针对具有共享资源的多智能体系统，提出了一种分层模型预测监督控制（MPSC）框架。MPSC将滚动时域成本最优控制与基于监督控制理论（SCT）的监督相结合，以强制执行安全性、非阻塞性和资源独占性。通过分层且可扩展的监督器和自动机模板，实现了可扩展性，无需整体合成即可进行分布式执行。利用该框架，本文开发了一个城市无人机系统交通管理（UTM）模型。该模型能够在时变需求下高效支持取送任务。

## Abstract
This work proposes a hierarchical Model Predictive Supervisory Control (MPSC) framework for multi-agent systems with shared resources. MPSC integrates receding-horizon cost-optimal control with Supervisory control theory (SCT) based supervision that enforces safety, nonblockingness, and resource exclusivity. Scalability arises from hierarchical and scalable supervisor and automaton templates, enabling distributed execution without monolithic synthesis. Using this framework, this work develops an urban Unmanned aircraft system Traffic Management (UTM) model. The model supports pickup-and-delivery missions under time-varying demand efficiently.

## 1. 核心问题与整体含义

- **研究背景**：随着无人机在物流、巡检、城市公共服务等场景中的普及，低空空域成为稀缺的共享资源，尤其在密集城市环境中，多无人机协同运行面临安全性、任务时效性、通信和分布式决策等多重挑战。
- **核心问题**：多智能体系统（如无人机群）在共享有限资源（航路、起降点、充电站等）时，如何在满足安全约束、避免冲突、保证任务完成（非阻塞性）的同时，实现成本最优和高效调度。
- **整体含义**：传统集中式监督控制或集中式路径规划在面对大量无人机和复杂航路网络时，会因状态空间组合爆炸而难以扩展；而纯分布式优化难以提供形式化的安全保证。论文提出的层次化模型预测监督控制（MPSC）框架，试图将监督控制理论（SCT）的安全保证与模型预测控制（MPC）的在线最优决策能力结合起来，为城市无人机交通管理（UTM）提供一种可扩展、安全且高效的解决方案。

## 2. 方法论：核心思想与关键细节

- **总体架构**：采用分层结构，上层为 UTM 监督层，下层为多架 UAV 自主决策层。
  - UTM 层基于 SCT 建立全局监督器，追踪整个机队的离散事件状态，计算“被禁止的事件集合” P，并将该集合广播给所有 UAV；
  - 每架 UAV 在自己被监督器允许的自动机子模型内，独立求解一个有限时域 MILP 优化问题，选择成本最小的下一个事件并执行；
  - 执行后再次滚动更新，形成“滚动时域 + 监督约束”的闭环。

- **核心技术与建模**：
  - 每个 UAV 被建模为多权重自动机，状态携带能量、时间和任务惩罚等代价向量；
  - 空域用多层多重图 \( M=(V,A) \) 表示，其中节点包括特殊节点（垂直起降场、供应商、客户端、充电站）和逻辑导航节点，层代表不同高度层；
  - 采用自动机的代数表示：利用邻接矩阵 \(A\)、事件可达矩阵 \(B\) 和事件可用矩阵 \(C\)，将状态转移写为:
  \[
  x_{t+1} = (A x_t) \odot (B u_t)
  \]
  其中 \(x_t\)、\(u_t\) 为 one-hot 编码，\(\odot\) 为 Hadamard 乘积；
  - 无人机子模型包括移动自动机、不同方向的边资源自动机、任务模式自动机、通信/活路/电池辅助自动机等，并通过地图、工作流、电池、位置-任务等规范自动机合成通用监督器模板；
  - 采用共享模板和事件重标记（relabeling）策略，将单一智能体监督器复制并实例化到各 UAV，从而避免整体积合成，使监督器状态规模不随 UAV 数量指数增长；
  - UTM 层通过顶点阻塞自动机、互斥规范和地理围栏规范，实时生成禁止事件集 P，以实现资源互斥、方向控制和地理围栏约束。

- **MPSC 优化问题**：在滚动时域内，UAV 求解如下 MILP：
  \[
  \min \; \alpha_S \sum_{t=0}^{H-1} w^\top x_t - \beta_I \sum_{i\in I}\sum_{t=0}^{H-1} (H-t) u_{t,i}
  \]
  并满足初始状态约束、自动机动力学约束、状态/事件 one-hot 约束、事件可行性约束，以及禁用事件集合 \(P\) 的约束。该目标函数同时考虑运行成本最小化和期望事件（如任务相关事件）的提前激励。
  - 优化通过 BFS 在当前监督器状态周围提取深度为 \(H\) 的子自动机，并执行结构校正，然后在该子自动机上求解 MILP，仅执行第一个最优事件，再滚动重复。

## 6. 主要结论与发现

- 层次化 MPSC 框架能够将 SCT 的严格安全/非阻塞性保证与 MPC 的在线优化能力结合起来；
- 通过模板化监督器和事件重标记，避免了整体合成，监督器规模与 UAV 种群数量脱钩，显著降低了计算复杂度；
- 在城市 UTM 取送任务场景中，该框架可以完成多机无冲突协同：R1 完成 4/4 任务，R2 完成 5/6 任务；R2 的吞吐率（2.46 次/分钟）高于 R1（1.29 次/分钟），而被禁止事件的数量也更多，说明系统在更高复杂度下仍能维持有界、安全的运行；
- 层次化结构允许每架 UAV 独立求解本地优化问题，UTM 层仅广播禁止事件集合，因而具有分布式执行和在线可扩展性的潜力。
