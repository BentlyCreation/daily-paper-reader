## 摘要
行人路径预测对于提升自动驾驶车辆和高级驾驶辅助系统的安全性至关重要。以往研究探索了行人路径预测的不同学习任务表述，并使用浅层神经网络对这些表述进行了比较，但未将这一分析扩展到更复杂的深度学习模型。本文将时空图注意力网络（STGAT）适配到一个统一的行人路径预测框架中，并引入了针对STGAT的状态和动作定义。由此产生的表述支持确定性策略和随机策略、一次性决策和顺序决策，以及包括REINFORCE和近端策略优化在内的强化学习算法。与标准监督学习表述相比，所提出的学习任务表述在选定的基准数据集上提升了预测性能。这些结果表明，重新表述决策过程和训练目标能够改进先进的行人轨迹预测架构，并可能为改进其他基于图的预测模型提供一条路径。

## Abstract
Pedestrian path prediction is crucial for enhancing the safety of autonomous vehicles and advanced driver-assistance systems. Previous studies explored different learning-task formulations for pedestrian path prediction and compared these formulations using shallow neural networks, but did not extend this analysis to more complex deep-learning models. This paper adapts the Spatial-Temporal Graph Attention Network (STGAT) to a unified pedestrian path prediction framework and introduces state and action definitions specific to STGAT. The resulting formulations support deterministic and stochastic policies, one-time and sequential decision-making, and reinforcement-learning algorithms including REINFORCE and proximal policy optimization. The proposed learning-task formulations improve prediction performance across the selected benchmark datasets compared with the standard supervised-learning formulation. These results demonstrate that reformulating the decision process and training objective can improve an advanced pedestrian trajectory prediction architecture and may provide a path toward improving other graph-based prediction models.

## 2. 方法论

### 2.1 总体思路

- 将STGAT视为一个策略网络，在统一PPP框架下将路径预测表述为强化学习问题。
- 定义新的**状态空间**、**动作空间**、**奖励函数**和**状态转移函数**，使STGAT能够适配不同学习范式：
  - 确定性策略 vs. 随机策略；
  - 一次性决策（ODM）vs. 顺序决策（SDM）；
  - 监督学习 vs. 逆强化学习 + 强化学习算法（REINFORCE、PPO）。

### 2.2 关键定义与公式

- **观测与预测**：观测前8个时间步（\(T_{\tau o}=8\)），预测未来12个时间步（\(T_{\tau f}=12\)）。
- **状态（State）**：定义为场景内所有行人的编码信息（由STGAT编码器生成）与已预测位置组成的向量；ODM中初始状态包含全体行人的8步观测轨迹，SDM中状态随预测逐步累加。
- **动作（Action）**：
  - ODM：单个动作包含单个行人全部12个未来坐标；
  - SDM：每个时间步输出一个下一个位置的二维坐标，共12个动作。
- **奖励函数（IRL）**：采用距离函数（平方L2范数）衡量预测状态–动作对与专家轨迹（ground truth）之间的差异：
  
  \[
  r_{t_\epsilon} = \left\|(\hat{s}_{t_\epsilon}, \hat{a}_{t_\epsilon}) - (s_{t_\epsilon}, a_{t_\epsilon})\right\|_2^2
  \]

- **折扣回报**：
  
  \[
  G(\varepsilon | s_{t_\epsilon}) = \sum_{l=t_\epsilon}^{T_\epsilon-1} \gamma^{l-t_\epsilon} r_l
  \]

- **目标函数**：最大化初始状态价值期望，即 \(J(\theta) = \mathbb{E}_{s_0 \sim b_0(s)}[V(s_0;\theta)]\)，并采用策略梯度定理更新参数。

### 2.3 STGAT适配细节

- STGAT由**两个LSTM模块（G-LSTM、M-LSTM）** 和**一个解码LSTM（D-LSTM）** 构成；GAT用于建模行人间的时空交互。
- 预训练分三阶段：前两阶段仅训练编码器（重构观测轨迹），共250 epochs；第三阶段联合训练整个模型（150 epochs），此时采用本文提出的不同学习任务表述进行微调。

### 2.4 提出的学习任务表述

- **SL-MSE**（ODM + 确定性监督学习）：动作是一次性输出的12步轨迹，\(\gamma=0\)，使用MSE损失，对应公式(6)。
- **SL-MSE-SPG**（ODM + 随机策略梯度）：通过固定噪声种子，从输出高斯分布（标准差0.05）采样，利用策略梯度定理进行更新，对应公式(7)。
- **SL-MSE-SDM**（SDM + 监督学习）：将每个行人视为独立决策智能体，动作逐时间步输出，状态随动作累加，状态转移函数 \(s_{t_\epsilon+1} = T(s_{t_\epsilon}, a_{t_\epsilon})\) 将当前动作附加到状态向量中；\(\gamma\) 可取不同值（消融实验），对应公式(9)。

### 2.5 价值网络设计

- 为REINFORCE with baseline和PPO设计了两种价值网络：
  - **简化基线（Simplified Baseline）**：仅输入单个行人的观测步；
  - **全状态基线（Full State Baseline）**：复用STGAT共享编码器，仅更新浅层3层稠密网络。

## 6. 主要结论与发现

- 标准监督学习（SL-MSE）并非最优表述：通过采用**PPO + 全状态基线**（ODM随机策略）或**SDM + 适当折扣因子**（\(\lambda=0.4\)），可以在几乎所有数据集上获得更低的ADE/FDE。
- 具体改进幅度：PPO with full state baseline在ETH上ADE降低约4%，Hotel上降低约11%；SDM在\(\lambda=0.4\)时相较SL-MSE在多数指标下降2%~13%。
- 随机策略本身不一定优于确定性策略：简单的REINFORCE（SL-MSE-SPG）总体不如SL-MSE；只有配合先进的RL算法（如PPO）才能体现优势。
- 价值网络的设计影响性能：对于REINFORCE，全状态基线显著优于简化基线；对于PPO，两种基线差异不大，但去掉基线会导致性能下降。
- SDM的累积状态转移使梯度更集中于预测轨迹的初始几步，说明行人离开观测窗口后的最初决策对整体预测质量至关重要。
