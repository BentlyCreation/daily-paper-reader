## 摘要
基于LLM的多智能体系统（MAS）通过协调多个智能体在复杂推理任务上取得了强劲性能，但代价是大量的令牌消耗。最近关于自动拓扑设计的工作ARG-Designer将该问题重新表述为自回归图生成。然而，其训练目标并未显式激励模型生成稀疏且高效的拓扑。我们通过引入受人类反馈强化学习（RLHF）启发的奖励引导自回归图生成（RGA-Designer）来解决这一局限性。我们训练了一个联合捕获任务正确性和结构紧凑性的奖励模型，然后使用该奖励模型作为反馈对预训练的图生成器进行微调。我们的方法在保持ARG-Designer水平下的任务准确性的同时，平均减少了20.5%的令牌消耗。

## Abstract
LLM-based Multi-Agent Systems (MAS) achieve strong performance on complex reasoning tasks by coordinating multiple agents, but at the cost of substantial token consumption. Recent work on automatic topology design, ARG-Designer, has reframed this problem as autoregressive graph generation. However, its training objective provides no explicit incentive for the model to generate sparse and efficient topologies. We address this limitation by introducing a Reward-Guided Autoregressive Graph Generation (RGA-Designer) inspired by Reinforcement Learning from Human Feedback (RLHF). We train a reward model that jointly captures task correctness and structural compactness, and then fine-tune the pretrained graph generator using the reward model as feedback. Our method preserves task accuracy at the level of ARG-Designer while reducing token consumption by an average of 20.5%.

## 2. 方法论

### 2.1 问题定义

- MAS 被表示为**有向无环图（DAG）**：节点为 LLM 智能体（带角色提示），边表示智能体间消息传递。
- 智能体 i 的输入由其角色、用户查询和前驱消息组装，输出 `m_i`；最终答案由输出节点聚合。
- 任务完成指示 `c(G,q)` 为 1 当且仅当最终答案与真实答案一致。
- 优化目标是最小化节点数和边数，同时满足 `c(G,q)=1`，即稀疏但有功能的拓扑。

### 2.2 方法整体框架

方法和 ARG-Designer 类似，分三个阶段（前置为预训练生成器）：

1. **预训练生成器（阶段 0）**：继承 ARG-Designer 的自回归图生成器，以条件对数似然为目标在查询-图上训练。
2. **数据集收集（阶段 1）**：
   - 用预训练生成器在不同采样温度下生成多个候选图，对每个图执行 MAS 得到成功/失败标签。
   - 同时利用 ARG-Designer 训练阶段已有的图/查询对，降低数据收集成本。
   - 每个样本的奖励 `r` 由公式(8)计算：
     \[
     r = \lambda_c c + \lambda_V \max(0, \frac{V_{\max}-|V|}{V_{\max}-1}) + \lambda_E \text{clip}(0,1, \frac{E_{\max}-|E|}{E_{\max}-E_{\min}})
     \]
     其中 \(\lambda_c=0.6, \lambda_V=0.3, \lambda_E=0.1\)，保证正确性优先、结构紧凑次之。
   - 构造偏好对：每对中至少一个样本成功，且奖励差大于阈值 \(\delta=0.05\)。
3. **奖励模型训练（阶段 2）**：
   - 奖励模型是基于 **GraphSAGE** 的图神经网络。
   - 节点特征 = 角色嵌入 + 查询嵌入（均为 384 维句子嵌入）+ 5 维结构特征（图大小、边数、生成顺序位置、入度、出度）。
   - 经过两层 GraphSAGE + 残差 + LayerNorm，再全局均值池化 + MLP 输出标量奖励。
   - 使用 **Bradley-Terry 成对排序损失**训练；pass/fail 对权重为 1.0，pass/pass 对权重为 0.1（减少冗余信息）。
4. **策略优化（阶段 3）**：
   - 采用 **GRPO**（Group Relative Policy Optimization）变体，on-policy 采样一组图，计算组内相对优势 \( \hat{A}_i = (\hat{r}_i - \mu)/\max(\sigma, \sigma_{\min}) \)。
   - 策略目标为最大化优势加上 KL 正则（约束新策略不偏离 ARG-Designer 参考模型），重要性比率恒为 1，因此省略裁剪项。
   - 推理时使用 **Best-of-N（N=5）**：采样多个图，选奖励模型打分最高的作为最终拓扑，采样和打分均由轻量模型完成，额外开销很小。

### 2.3 关键创新点

- 用奖励模型替代人类反馈，属于 RLVR（可验证奖励强化学习）范式。
- 奖励模型在嵌入空间中编码图，**可以跨数据集复用**，也支持未见过的角色；而 ARG-Designer 的节点生成器需扩展分类头并重训。

## 6. 主要结论与发现

- RGA-Designer 在**所有六个基准上保持或略优于 ARG-Designer 的准确率**，且没有统计显著的精度下降。
- Token 消耗平均减少 **20.5%**，与 ARG-Designer 相比在 5/6 个数据集上统计显著；MultiArith 不显著的原因是题目模板化、语言变化少、本身可被极简拓扑解决，几乎没有冗余可压缩。
- 与 G-Designer、AgentPrune、AgentDropout 相比，RGA-Designer 在 token 消耗上全面显著更低，且精度不差。
- 奖励模型可在嵌入空间评分图结构，因此**跨数据集共享训练数据，且能处理未见角色**，相比 ARG-Designer 更具可扩展性。

## 7. 优点

- **方法创新**：将 RLHF/RLVR 引入自回归图生成，解决原有似然训练无稀疏激励的缺陷。
- **奖励模型设计合理**：联合建模正确性和紧凑性，且权重设计保证正确性优先，不会为了稀疏牺牲任务完成度。
- **训练效率**：复用 ARG-Designer 已有样本，减少数据采集开销；奖励模型跨数据集共享。
- **策略优化简洁**：on-policy GRPO，省去重要性采样和 clipping，实现简单。
- **实验严谨**：10 次重复、Welch t-test、多基线和消融，可信度较高。

## 8. 不足与局限

- **LLM 主干单一**：所有实验只用 Qwen3-4B，更换主干模型时需重构整个训练数据集（因成功/失败标签依赖特定 LLM），结果泛化性有限。
- **依赖可验证答案**：需要 ground-truth 标签，只能用于代码生成、多项选择等有明确答案的任务；开放生成式任务无法直接适用。
- **算力细节缺失**：未报告奖励模型训练和策略优化的 GPU 时间、总能耗，可复现性稍受影响。
- **消融覆盖不全**：仅在 3 个数据集上做消融，未对全部六数据集验证各组件贡献。
- **统计显著性不完全**：MultiArith 上 token 削减不显著，说明方法对简单模板化任务收益有限。
- **潜在偏差风险**：基线方法的超参数可能未充分调优，且模型推理采用 Best-of-N 策略，可能引入额外选择偏见。
