## 摘要
仅相机4D占用预测使自动驾驶车辆能够仅从历史多视图图像预测未来的3D语义场景，这对驾驶安全至关重要。尽管现有方法已取得良好性能，但输入多视图帧之间的强时空建模仍未得到充分探索，这限制了这些方法在未来4D预测中的性能。为解决这一差距，我们提出了一种新颖的框架InterOCF，用于4D占用预测，该框架联合建模基于3D体素的表示和多视图分割序列中的时间动态，同时明确纳入2D和3D分支之间的特征交互。我们的框架包含三个核心组件：1）3D时空（3DST）模块，从历史体素状态学习体积动态以预测未来体素状态；2）2D时空（2DST）模块，采用辅助的多视图时间分割预测任务增强时间语义动态；3）时空交互建模（STIM）模块，实现2D和3D表示之间的特征交互。在nuScenes、Lyft-Level5和nuScenes-Occupancy数据集上的实验表明，InterOCF持续优于现有基线方法。

## Abstract
Camera-only 4D occupancy forecasting enables autonomous vehicles to predict future 3D semantic scenes solely from historical multi-view images, which is critical for driving safety. Even though current methods have achieved good performance, the strong spatial-temporal modeling between the input multi-view frames is still underexplored, which limits the performance of those methods in future 4D forecasting. To address this gap, we introduce a novel framework, InterOCF, for 4D occupancy forecasting that jointly models temporal dynamics in both 3D voxel-based representations and multi-view segmentation sequences, while explicitly incorporating feature interaction between the 2D and 3D branches. Our framework incorporates three core components: 1) A 3D Spatio-Temporal (3DST) module that learns volumetric dynamics from historical voxel states to predict future voxel states; 2) A 2D Spatio-Temporal (2DST) module employing an auxiliary multi-view temporal segmentation forecasting task to enhance temporal semantic dynamics; 3) A Spatio-Temporal Interaction Modeling (STIM) module that enables feature interaction between 2D and 3D representations. Experiments on the nuScenes, Lyft-Level5, and nuScenes-Occupancy datasets show that InterOCF consistently outperforms existing baseline approaches.

- **现有方法的局限**：当前主流方法大多采用“纯 3D 范式”——即将多视图图像一次性提升（lift）并融合到 3D 空间后，直接在稀疏体素空间中进行时序推演。作者指出该范式存在三点不足：
  1. 图像域表示被过早丢弃，丢失了高分辨率外观细节等丰富的视角专属线索；
  2. 直接在稀疏 3D 占用空间中做时序展开效率低且不稳定，长期预测容易产生误差累积；
  3. 现有方法未显式建模 2D 多视图表示与 3D 占用动态之间的相互交互。
- **核心问题**：输入多视图帧之间的时空关系建模不足，限制了现有方法在未来 4D 场景预测上的性能。
- **论文含义**：本文提出 **InterOCF** 框架，通过**联合建模 2D 图像空间和 3D 体素空间中的时空动态**，并**显式引入跨分支特征交互**，从而提升仅相机 4D 占用预测的准确性和鲁棒性。

## 2. 论文提出的方法论

### 核心思想
- 采用 **2D-3D 交互式预测范式**：同时进行 2D 多视图分割序列预测和 3D 体素占用预测，并在两者之间建立双向特征交互，以互补几何推理与语义/外观信息。

### 整体架构
输入为过去和当前时刻的多视图图像序列 \(\{I_t\}_{t=-m}^{0}\)（m 为历史帧数，t=0 为当前帧）。图像骨干网络（ResNet-34 + 可变形卷积）提取每帧的 2D 图像特征，同时送入两个分支：

- **2D 分支**：由 2D 时空模块（2DST）处理，预测未来多视图图像特征，并通过分割头生成语义分割序列。
- **3D 分支**：通过 LSS（Lift, Splat, Shoot）将 2D 特征提升至 3D 体素空间，得到历史体素特征序列，再送入 3D 时空模块（3DST）进行时序建模。
- **STIM 模块**：在 3DST 的上下文特征和 2DST 的融合特征之间进行多尺度跨注意力交互，增强两个分支的表征。

### 关键技术细节

#### 2D 时空模块（2DST）
- 输入历史多视图图像特征，预测当前和未来的多视图图像特征，并用于辅助的**未来语义分割预测任务**。
- 提出 **Masked Inter-view Attention (MIA)**：由于相邻相机之间存在视野重叠，将每个视图的特征沿宽度方向池化为列向量，然后只允许自身与相邻视图进行注意力交互，减少计算开销并增强跨视角语义一致性。
- 融合后的特征不仅用于 STIM 交互，还会通过 3D 转置卷积等模块恢复未来时间维度并输出预测的图像特征序列，配合分割头产生监督信号。

#### 3D 时空模块（3DST）
- **低分辨率分支**：使用基于 ResNet3D 的体素编码器将输入体素序列下采样至一半空间分辨率，再通过 **Pre-LSTM** 在滑动窗口内自回归地预测未来低分辨率体素状态序列。
- **高分辨率分支（上下文分支）**：为避免低分辨率建模丢失细节，使用上下文编码器（ResNet3D）从原始体素序列中提取高分辨率上下文特征 \(F_{ctx}^{enc}\)。
- 上下文特征先送入 STIM 与 2D 分支交互得到精细化特征，再与低分辨率未来预测拼接，并由 **Post-LSTM** 进一步融合时序信息与空间细节。
- 最后将输出上采样至原始分辨率，并与上下文特征拼接，经 3D 卷积解码器生成最终未来体素预测。

#### 时空交互建模（STIM）
- 输入：3DST 的上下文特征 \(F_{ctx}^{enc}\) 和 2DST 的融合多视图特征 \(\{\bar{F}^v\}_{v=1}^{V}\)。
- 将上下文特征**逐步下采样两次**，构建两级特征金字塔，然后采用**自底向上的跨注意力交互**：
  - 最低分辨率特征先与 2D 融合特征做 cross-attention（3D 特征作 query，2D 特征作 key/value）；
  - 输出上采样后与中间分辨率特征残差相加；
  - 再次与 2D 特征进行 cross-attention，输出上采样后加回原始上下文特征，得到精细化上下文表示。
- 这种方式实现从粗到细的跨模态融合，既保留 3D 空间结构，又补充 2D 外观细节。

#### 训练损失
- 2D 分割任务使用交叉熵损失（权重 0.05）；
- 3D 占用预测使用交叉熵损失（权重 0.5）；
- 光流预测使用 smooth L1 损失（权重 0.5）。

- 遵循 **Cam4DOcc** benchmark 的评估设置：
  - 每个序列包含 7 帧：3 帧观测（两帧过去 + 当前帧）和 4 帧未来预测。
  - 预测范围为水平面 \([-51.2\text{m}, 51.2\text{m}]\)，垂直方向 \([-5\text{m}, 3\text{m}]\)，体素大小为 0.2m，网格分辨率 \(512 \times 512 \times 40\)。

- 评估指标：当前帧 IoU（IoU c）、未来帧平均 IoU（IoU f）、整个预测范围内的 IoU（Io eUf）。

## 6. 主要结论与发现

- 通过在 2D 多视图空间和 3D 体素空间同时进行时空建模，并显式加入跨维度交互，可以显著提升仅相机 4D 占用预测性能。
- **Inflated GMO 任务**：在 nuScenes 上，InterOCF 将 IoU f 从 OccProphet 的 26.94 提升到 28.73；在 Lyft-Level5 上达到 43.72 IoU c、39.57 IoU f、40.55 Io eUf，全面优于所有基线。
- **细粒度 GMO 任务**：在 nuScenes-Occupancy 上，InterOCF 获得 15.71 IoU c、11.63 IoU f、12.12 Io eUf，优于 OccProphet 等所有对比方法。
- **细粒度 GMO + GSO 任务**：InterOCF 在动态和静态物体预测上均取得最佳结果，尤其未来动态物体 Io eUf 相比 OccProphet 提升 5.1%。
- 消融实验显示：3DST、2DST、MIA、STIM 每个组件均有正向贡献；2D 预测帧数与 3D 分支输出长度一致（5 帧）时效果最佳；LSTM 作为时序模型优于 GRU 和 Transformer。
- 计算效率方面：与 OccProphet 相比，InterOCF 在提升精度的同时降低了显存占用（24G → 22G），推理速度基本持平（4.5 vs 4.3 FPS）。

## 7. 优点

- **方法创新性**：突破了纯 3D 占用预测范式，首次在同一框架内联合 2D 多视图分割预测和 3D 体素预测，并设计双向交互机制，思路新颖。
- **2D 辅助任务设计合理**：利用 SAM 自动生成多视图分割标签，无需人工标注；通过未来分割预测引入语义时序正则，有效辅助 3D 几何推理。
- **跨视图注意力（MIA）高效**：仅允许相邻视图交互，符合相机重叠视野的物理规律，同时控制计算量。
- **3DST 分层设计**：在低分辨率体素空间建模全局运动，在高分辨率上下文分支保留细节，兼顾效率与精度。
- **实验全面**：覆盖多个数据集、多种任务粒度、多种对比方法和消融实验，验证了各模块的有效性；可视化结果直观展示了方法的优越性。

## 8. 不足与局限

- **消融实验覆盖有限**：所有消融实验仅在 Lyft-Level5 上完成，未报告在其他数据集上的消融结果，部分结论可能受单数据集特性影响。
- **对比公平性存疑**：2D 分割标签使用 SAM 自动生成，可能引入标签噪声；不同方法对辅助监督的依赖程度不同，直接比较时可能存在隐含偏差。
- **2D 辅助任务依赖额外标注流程**：虽然无需人工标注，但 SAM 生成标签的质量和成本未深入分析，对最终预测的影响缺乏敏感性实验。
- **时序模型对比不够深入**：Transformer 表现不如 LSTM 的原因仅给出推测（序列较短、训练规模有限），未做进一步实验验证（如增加训练轮次或调整注意力实现）。
- **长期预测能力未充分验证**：实验仅覆盖 4 帧未来预测（2 Hz/5 Hz），未展示更长预测时域下的表现；低分辨率时序建模的误差累积问题在更长时域下可能更突出。
- **数据多样性受限**：实验基于三个自动驾驶数据集，但均以城市道路场景为主，未在极端天气、特殊路况等场景下进行测试。
- **未报告不确定性/鲁棒性分析**：没有涉及输入噪声、丢失相机、不同天气条件下的性能退化情况。
