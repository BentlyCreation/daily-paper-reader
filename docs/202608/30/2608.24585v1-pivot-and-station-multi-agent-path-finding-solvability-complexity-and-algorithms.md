## 摘要
自动化高密度存储系统（仓库、机器人停车、工厂物流等）需要智能体车队在稀缺的任务关键资源间移动，然后停泊而不阻碍未来操作。我们提出了旋转与站点多智能体路径规划（PS-MAPF），一种MAPF变体，其中一部分有任务的智能体必须访问一组可互换的旋转点（例如工作站）之一，然后整个车队终止于匿名站点，每个站点一个智能体。我们完全刻画了可解性：在2边连通图上的每个实例都可解，并且在任意连通图上，相对于未占用顶点数量的结构性有效距离度量给出了充分必要条件。我们证明即使使用单个旋转点，最小化站点完工时间或站点流时间已经是NP困难的。我们提出了三种算法：一种完整的基线算法、一种基于SAT的最优求解器，以及旋转优先规划（PPP），后者在基准实例中解决了74-89%的问题，其完工时间和流时间比基线低几个数量级。

## Abstract
Automated high-density storage systems (warehouses, robotic parking, plant logistics, etc.) require fleets of agents to move through scarce task-critical resources and then park without obstructing future operations. We introduce Pivot-and-Station Multi-Agent Path Finding (PS-MAPF), a MAPF variant in which a subset of tasked agents must each visit one of a set of interchangeable pivots (e.g., workstations) before the entire fleet terminates at anonymous stations, one agent per station. We characterize solvability completely: every instance on a 2-edge-connected graph is solvable, and, on arbitrary connected graphs, a structural effective-distance measure relative to the number of unoccupied vertices gives a necessary and sufficient condition. We prove that minimizing station-makespan or station-flowtime is NP-hard already with a single pivot. We present three algorithms, a complete baseline, a SAT-based optimal solver, and Pivot-Prioritized Planning (PPP), the last solving 74-89% of benchmark instances with makespan and flowtime orders of magnitude below the baseline.

## 论文核心总结：Pivot-and-Station Multi-Agent Path Finding (PS-MAPF)

### 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：高密度自动化存储系统（如 Ocado、Amazon Sequoia 等仓库、机器人停车场、工厂物流）中，大量智能体（机器人、穿梭车等）需要在固定轨道/网格拓扑上行驶。其中一部分"任务智能体"必须先访问一个任务关键资源（文中称为 **pivot**，如工作站、取货点），随后整个车队（包括无需访问 pivot 的智能体）必须停泊到若干匿名站点（**station**），每站一个智能体，不得阻塞后续操作。
- **核心痛点**：现有 MAPF 变体均未完整建模"必须先访问可互换中间资源、再进行全队匿名停泊"的约束组合。例如：
  - Anonymous MAPF 不考虑中间资源；
  - TAPF 只有分组内可互换终点；
  - Multi-Agent Pickup and Delivery 是持续型任务且目标分配是固定的；
  - MCPF 要求每个目标被访问，但方向相反（PS-MAPF 中可能没有任何智能体需要某个 pivot）。
- **研究意义**：该问题直接来源于现实仓储调度，且其复杂性尚未被研究。论文首次形式化定义 **PS-MAPF**，并系统回答了三个基础问题：何时可解？优化难度如何？如何高效求解？

### 2. 论文提出的方法论

#### 2.1 问题定义
- 输入为连通无向图 G=(V,E)、pivot 集合 P、station 集合 S、任务智能体集合 At、非任务智能体集合 Au（At∩Au=∅）、初始位置 o（一一映射，|S|≥|A|）。
- 成功路径需满足：任务智能体需先到达任一 pivot，再到达且停留在某个 station；非任务智能体直接到达 station；任意两条路径无顶点冲突（vertex conflict）和边交换冲突（swapping conflict）。
- 优化目标：**Station-Makespan**（所有智能体到达站点的时间最大值）和 **Station-Flowtime**（时间总和）。

#### 2.2 可解性理论
- **2-edge 连通图上的充分性**（定理 1）：若每个任务智能体的初始位置与某个 pivot 是 2-edge 连通的（即存在两条边不相交的路径），则实例必可解；因此任何具有至少一个 pivot 的 2-edge 连通图上的实例全部可解。
- **一般连通图上的充要条件**（定理 2 + 引理 2）：
  - 定义 2-edge 连通分量、其凝聚树、以及"p-adapted 配置"（所有空格形成包含 pivot 的连通区域）。
  - 定义**有效距离** deff(p)(o(i))，它刻画了在凝聚树上从初始位置所在分量到 pivot 所在分量途中必须经过的"瓶颈"长度。
  - 核心条件：存在从初始配置可到达的 p-adapted 配置 c，使得 deff(c(i)) ≤ h(V,o)=|V|-|A|（未占据顶点数）。
  - 该条件可在多项式时间内检验（对每个 pivot 做一次 p-adaptive 归约，再检查每个任务智能体的有效距离）。
- **充分但非必要的简单条件**（命题 3）：well-formed 实例（每个任务智能体存在一条到 pivot 且不经过其他智能体初始位置的路径）必可解，实验中使用该条件生成实例。

#### 2.3 复杂度结果
- 通过从 3SAT 归约，构造一个**单一 pivot** 的 PS-MAPF 实例：
  - 最小化 Station-Makespan 是 NP-hard（定理 3）；
  - 最小化 Station-Flowtime 是 NP-hard（定理 4，通过证明在构造实例上二者最优性等价）。
- 这构成了尖锐的复杂度跳跃：无任务（仅匿名停泊）时可多项式求解（匿名 MAPF），但引入哪怕一个 pivot 就变得 NP-hard。

#### 2.4 算法设计
| 算法 | 类型 | 核心思想 | 复杂度 |
|------|------|----------|--------|
| **BA（Baseline，完整）** | 完整但质量低 | 利用定理 2 的构造性证明：逐任务智能体将系统归约到 p-adapted 配置，沿凝聚树用"空位移动+2-edge 旋转"将智能体送到 pivot，再反转运动恢复初始配置；最后用匿名 MAPF 流程收尾。 | O(n^4) |

### 6. 主要结论与发现

- **可解性**：2-edge 连通图上任何实例都可解；一般连通图上的可解性由有效距离 ≤ 未占用顶点数这一充要条件刻画，且可在多项式时间检验。
- **复杂度**：即使只有单个 pivot，最小化 Station-Makespan 和 Station-Flowtime 均为 NP-hard——匿名停泊（可多项式求解）与 pivot 约束组合后问题难度急剧上升。
- **算法表现**：
  - BA 虽然完备，但实际运行极慢（60 秒内无法求解任何最优实验实例），且解质量差。
  - PPP 在 benchmark 上达到 **74–89% 的成功率**，Makespan 和 Flowtime 比 BA **低 2~3 个数量级**，运行时间也大幅低于 BA。
  - SAT 最优求解器在高密度/多任务场景下耗时显著，但可在小规模实例上获得最优解。
  - 启发式排序中 **MC（冲突最多优先）整体最强**：在两个密集地图上平均耗时最低、在空地图上成功率最高。

### 7. 优点

- **理论完备**：对可解性给出完整的充要条件，且可多项式检验；复杂度下界分析严格（3SAT 归约）。
- **问题定义新颖且贴近实际**：首次将"可互换中间资源 + 匿名终点 + 部分任务/非任务混合"纳入统一 MAPF 框架。
- **算法层次分明**：从完备但慢（BA）到最优但指数（SAT）再到快速但不完备（PPP），形成清晰的方法图谱，且 PPP 具备正确性证明。
- **编码设计巧妙**：SAT 编码借助"匿名性 + 两种状态（pivot-oriented/station-oriented）"消除对 |A| 的依赖，在密集场景中极具扩展潜力；并配套推导了紧下界（定理 6）显著减少不可满足查询次数。
- **实验分析细致**：对失败模式（pivot 数量过少 + 任务比例过高导致 Phase 2 流不饱和）有解释；对下界紧致性有专门分析。

### 8. 不足与局限

- **算法完备性缺失**：PPP 不保证完备，在瓶颈场景（1~5 个 pivot、75–100% 任务比例）会显著失败；虽优于 BA，但无最坏情况保证。
- **最优求解器规模受限**：伪布尔编码在最坏情况下指数级，实验局限在 28×28 网格内；依赖 BA 提供上界，若 BA 超时则无法启动。
- **实验偏差风险**：
  - 大规模实验仅用 well-formed 实例，这类实例天然易于 PPP 成功，可能高估其实际泛化能力；
  - 障碍物密度超过 30% 即无法构造可解实例，对高密度/狭窄通道场景结论有限；
  - 未与主流 MAPF 最优/次优求解器（CBS、LaCAM* 等）进行系统对比，缺少相对定位。
- **成本函数的局限**：仅考虑基于到达时间的目标，未考虑能量消耗、任务优先级、pivot 排队等待时长等现实因素。
- **模型简化**：pivot/station 均视为同质可互换，若实际系统存在多类 pivot（文中仅提及扩展方向）则不适用。
