## 摘要
机器人策略主要使用经典的参数化变体的模仿学习或强化学习进行训练，其中训练将智能体的行为完全存储在策略的网络参数中，给表示学习算法带来了沉重负担。我们提出了一种配备非参数记忆的新型导航智能体，该记忆显式索引导致关键事件的先前步骤。其优势有两方面：首先，它允许策略将部分行为外包给显式记忆；其次，它通过允许智能体在部署期间从测试情节中收集数据，从而更好地泛化到分布外（OOD）情况，鼓励了一种持续学习的形式。在社交导航的背景下，我们展示了这提高了智能体保留稀疏、高成本失败（如与人类碰撞）的能力。如果策略在模拟中训练，这也自然而然地部分解决了模拟到现实差距，通过将一些决策基于真实数据。我们将显式记忆集成到循环PPO架构中，并使用隐藏状态进行记忆检索以捕捉连续的时空动态。利用罕见、高影响事件的目标是通过利用强化学习智能体的优势信号来实现的。我们在模拟中结合逼真渲染和非视觉人群模拟来训练我们的智能体，并表明该智能体对OOD社会行为具有鲁棒性。

## Abstract
Robot policies are predominantly learned with classical parametric variants of imitation learning or RL, where training stores the agent's behavior exclusively in the policy's network parameters, putting a heavy burden on the representation learning algorithm. We propose a new navigation agent equipped with non-parametric memory which explicitly indexes prior steps leading to critical events. The advantages are twofold: first, it allows the policy to outsource some of its behavior into an explicit memory; second, it encourages a form of continual learning by allowing an agent to collect data from its testing episodes during deployment and therefore to better generalize to OOD situations. In the context of social navigation, we show that this improves the agent's capability to retain sparse, high-cost failures, such as human collisions. If the policy is trained in simulation, this also naturally addresses the sim-to-real gap, partially, by basing some of the decision making on real data. We integrate the explicit memory into a recurrent PPO architecture and use hidden states for memory retrieval to capture continuous spatiotemporal dynamics. The goal of exploiting rare, high-impact events is achieved by leveraging the RL agent's advantage signals. We train our agent in simulation with a combination of photorealistic rendering and non-visual crowd simulation and show that the agent is robust with respect to OOD social behavior.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：社交导航中的机器人策略主要采用参数化的模仿学习或强化学习训练，将全部行为知识压缩到网络权重中，导致表示学习负担重，且难以有效保留稀疏、高成本的失败事件（如与行人碰撞）以及应对分布外（OOD）场景。
- **关键挑战**：

  - 传统RL平均化经验的方式会使关键的高误差信号被稀释。
  - 模拟训练的策略难以直接迁移到真实环境（sim-to-real gap）。
- **研究意义**：该论文提出一种**优势驱动的显式记忆**（Advantage-Driven Explicit Memory），使策略能够将部分行为决策“外包”给非参数显式记忆，从而在部署中利用测试数据持续学习，提升OOD泛化能力和对稀有高影响事件的保留能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 受检索增强生成（RAG）启发，将**非参数外部记忆**集成到循环PPO策略中。
- 利用RL的优势信号（advantage）来识别和保留罕见高影响事件。
- 记忆条目被构造为“行动-结果记分卡”（Scorecard），显式关联早期动作与其延迟后果。

### 2.2 整体架构
- 基座策略沿用Janny等人[13]的循环PPO架构（GRU），并新增人类编码器（Transformer-based Wayformer模块）处理周围行人的轨迹特征。
- 记忆模块包含三个组成部分：**记忆收集**、**记忆检索**和**记忆融合**。

### 2.3 记忆收集：如何选择关键经验
- **训练阶段（离线选择）**：
  - 使用广义优势估计（GAE）计算每个时间步的优势值：
    \[
    \tilde{A}_t = r_t + \gamma \tilde{V}_{t+1} - \tilde{V}_t + \lambda\gamma \tilde{A}_{t+1}
    \]
  - 按优势绝对值 \(|A_t|\) 排序，保留top 5%的步骤作为关键事件存入记忆。
  - 采用**k步回溯**（k=6）机制：当时间 \(t_n\) 发生高影响事件时，存储从 \(t_n - k\) 步起的隐藏状态和动作，从而捕获事件的因果前兆，使智能体能提前预防类似情况。
- **部署阶段（在线选择）**：
  - 使用物理启发式替代GAE标签，如：基于评论家预测值的时序差分 \(|\tilde{V}_{t+1}-\tilde{V}_t|\)，或基于稀疏奖励（成功=+1，失败=-1）的伪标签。
  - 支持人工标注覆盖（+1表示值得模仿，-1表示应避免）。
- **记忆条目构成**：
  \[
  m_n = f_m(f_c(h_{t_n-k}) \oplus E[a_{t_n-k}] \oplus f_v(\bar{Q}_{t_n}))
  \]
  其中 \(\bar{Q}_t = \tanh(\tilde{V}_t + \tilde{A}_t)\) 是饱和Q值估计，取值范围[−1, 1]。
- **记忆库维护**：FIFO队列，容量N=512（可扩展到4096）。

### 2.4 记忆检索与融合
- 使用GRU隐藏状态 \(h_{t-1}\) 作为查询，同样使用存储的隐藏状态 \(h_n\) 作为键，通过两层MLP投影到共享检索空间，计算余弦相似度。
- 选择top-K（K=5）最相关记忆，softmax归一化后加权聚合，得到融合特征 \(\hat{m}_t\)，拼接到GRU输入。
- 引入**正交正则化损失**（Orthogonal Regularization Loss）防止表征崩溃，提升检索判别力。

### 2.5 训练目标
- 使用PPO训练策略和评论家，奖励函数为：
  \[
  r = R_{succ}\cdot \mathbb{1}_{succ} - R_{dist}\Delta_{dist} - C_{colli}\cdot \mathbb{1}_{colli} - C_{slack}
  \]
  其中 \(R_{succ}=2.5\)、\(R_{dist}=1.0\)、\(C_{colli}=0.1\)、\(C_{slack}=0.01\)。

## 6. 论文的主要结论与发现

- 显式记忆在ID场景下将成功率从76.16%提升到81.28%（+5.12%），同时保持较低的人类碰撞次数。
- 在OOD场景中，静态离线记忆提升有限（SR 54.00%→56.40%），而**在线构建的记忆缓冲**显著提升性能（SR→60.00%），并降低人类碰撞次数（3.64→3.24），且无需梯度更新。

- 记忆检索的推理延迟极低（0.10ms~0.125ms），不损害实时控制能力。
- 显式记忆作为一个“非参数”缓冲区，天然支持持续学习和sim-to-real迁移。

## 7. 优点：方法或实验设计上的亮点

- **方法创新性**：将RAG思想引入社交导航RL，首次利用优势信号选择关键经验存入显式记忆，解决了参数化策略中稀有高影响信号被稀释的问题。
- **k步回溯机制**：存储“危险或重要事件的前6步”的记忆状态，使智能体能在相似场景早期做出预防性反应，而非事后应对。
- **在线自适应能力**：部署阶段无需反向传播，即可通过在真实环境中收集经验填充记忆缓冲，实现即时行为调整，部分缓解sim-to-real gap。
- **设计细致**：正交正则化避免表征崩溃；tanh饱和Q值使标签语义直观（+1模仿、−1规避）；FIFO替换策略抑制记忆漂移。
- **实验规范**：区分ID/OOD、基线对比合理、消融实验覆盖关键设计选择。
