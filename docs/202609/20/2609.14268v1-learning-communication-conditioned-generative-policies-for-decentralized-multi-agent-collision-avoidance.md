## 摘要
在这项工作中，我们提出了一种用于多智能体碰撞避免的去中心化通信条件生成框架。智能体使用基于流匹配（flow-matching）的策略生成短时域动作序列，该策略由可访问全局状态的特权离线演示训练得到。演示中不包含显式通信信号；相反，智能体学习在部分可观测条件下交换并聚合编码交互相关意图的潜在消息。该形式化方法支持测试时的灵活推理：无条件生成对应于独立行为，而通信条件生成则无需集中式规划即可实现协同交互。由此得到的策略在执行时以完全去中心化的方式运行，仅依赖局部观测和习得消息。结合滚动时域（receding-horizon）推理方案，所提方法能够高效地单步推理短时域动作序列，并在通信中断时优雅降级。大量仿真结果表明，该方法具有接近专家水平的碰撞避免性能，并能强泛化到更密集、未见过的多智能体场景，同时可零样本迁移至真实机器人实验。

## Abstract
In this work, we propose a decentralized communication-conditioned generative framework for multi-agent collision avoidance. Agents generate short-horizon action sequences using a flow-matching policy trained from privileged offline demonstrations with access to global state. The demonstrations do not include explicit communication signals; instead, agents learn to exchange and aggregate latent messages that encode interaction-relevant intent under partial observability. This formulation supports flexible inference at test time, where unconditioned generation corresponds to independent behavior and communication-conditioned generation enables coordinated interaction without centralized planning. The resulting policies operate in a fully decentralized manner at execution time, relying only on local observations and learned messages. Combined with a receding-horizon inference scheme, the proposed approach enables efficient single-step inference of short-horizon action sequences and degrades gracefully under communication dropouts. Extensive simulation results demonstrate near-expert collision avoidance performance and strong generalization to denser, unseen multi-agent scenarios, along with zero-shot transfer to real-robot experiments.

## 1. 核心问题与整体含义

- **研究背景**：多智能体导航（自动驾驶、仓储机器人、空中集群、行人建模）要求智能体在共享空间中各自抵达目标并避免碰撞。去中心化条件下，智能体只能依赖局部观测、在部分可观测下行动，缺少显式协调机制，问题尤为困难。
- **现有方法的局限**：
  - 经典方法（RVO、ORCA）依赖对动力学、感知精度与互惠服从的强假设，在密集或异构场景中性能退化。
  - 学习型方法（CADRL、扩散式规划）表现良好，但多假设集中控制或执行期可访问全局特权状态，难以直接用于完全去中心化场景。
  - 现有学习型通信研究多聚焦于感知层（检测、跟踪），与下游决策、闭环评估结合不足；控制论方法虽可提供分布式优化与安全保证，但依赖手工通信协议与显式模型，表示灵活性受限。
- **核心论点**：确定性回归策略在交互环境中脆弱（多模态动作分布 + 分布漂移导致误差累积）；生成模型（扩散、流匹配）天然适合建模多模态交互策略。通信应被视为**表示学习问题**——学什么发、怎么聚合、如何用于交互感知决策，并端到端优化。
- **整体含义**：提出一个去中心化、通信条件化的流匹配生成策略框架，在训练时利用特权专家示范，在执行时仅靠局部观测与学得消息即可协调，为可扩展、抗通信退化的多智能体避碰提供生成式基础。

## 2. 方法论

### 2.1 问题设定与观测模型
- N 个同质智能体（动力学、观测模型、策略架构、通信协议一致），圆形独轮车动力学，差异仅在状态、尺寸与目标。
- 局部观测（自我中心坐标系）包含：到目标距离 $d^{goal}_i$、朝向目标的相对航向 $\phi_i$、偏好速度 $v^{pref}_i$、自身体半径 $r_i$，以及**最近邻**智能体的相对位置/速度分量 $(p^\parallel, p^\perp, v^\parallel, v^\perp)$。只取最近邻以保证可扩展性并反映真实感知限制。
- 动作空间：每步控制量 $a_i = [v_i, \Delta\theta_i]^\top$；策略输出长度 K 的短时域动作序列 $A^{(t)}_i \in \mathbb{R}^{K\times 2}$，仅执行第一个动作，滚动时域推进。
- 终止条件：全部到达（容差 $\varepsilon_{goal}$）、发生碰撞（$|p_i - p_j| \le r_i + r_j$）或超过最大时域 $T_{max}$。
- **训练数据**：由 CADRL 这一特权专家（可访问所有智能体状态）生成，示范中**不含显式通信信号**，但体现了集中信息下的协调避碰行为。

### 2.2 通信模块（消息生成—交互编码—注意力聚合）
- **消息发射**：$m^{(t)}_i = M_{\theta_1}(o^{(t)}_i)$，共享编码器逐智能体独立应用，压缩为 d 维隐消息（不要求显式编码物理状态或未来动作）。
- **成对交互编码**：对有序智能体对 $(i,j)$ 生成交互 token $z^{(t)}_{ij} = I_{\theta_2}(m_i, m_j)$，并计算兼容性打分 $\alpha^{(t)}_{ij} = \alpha_{\theta_3}(m_i, m_j)$，自交互被掩码。
- **注意力聚合**：对打分做 softmax 归一化得到权重 $w_{ij}$，聚合向量 $\bar{m}^{(t)}_i = \sum_{j\neq i} w_{ij} z_{ij}$。该聚合**置换不变**，仅依赖本地交换的消息，可解释为对他人交互相关信息的一种“软共识”，无需显式协议或共享计划。
- 通信模块轻量、不含特权信息，与生成策略联合训练，并受辅助蒸馏目标塑形。

### 2.3 通信条件生成策略（流匹配）
- 线性插值：$A_\tau = \tau A^{(t)}_i + (1-\tau)\epsilon$，$\tau \sim U[0,1]$，$\epsilon \sim \mathcal{N}(0,I)$；$\tau=0$ 为噪声、$\tau=1$ 为数据。
- 条件速度场 $u_\theta(A_\tau, o^{(t)}_i, \tau, \bar{m}^{(t)}_i)$ 由神经网络实现，**条件流匹配损失** $L_{CFM}$ 回归目标速度 $(A^{(t)}_i - \epsilon)$；梯度同时回传至生成策略与通信模块，实现端到端交互感知学习。
- **无条件流匹配损失** $L_{UFM}$（以空嵌入 $\varnothing$ 为条件）仅正则化基础生成动力学、稳定训练，**不向通信模块回传梯度**，确保消息只由交互相关的条件生成目标塑造，而非边际动作统计。

### 2.4 特权教师与蒸馏
- **特权交互 Transformer 教师**：$h^{(t)} = T_\phi(\{(o^{(t)}_i, g^{(t)}_i)\}_{i=1}^N)$，其中 $g^{(t)}$ 为仅训练期可用的全局参考信息（全局自身与目标坐标）。
- **教师训练目标**：$L_{intent} = \mathbb{E}\|D_\psi(h^{(t)}_i) - o^{(t+1)}_i\|_2^2$，用轻量解码器 $D_\psi$ 重建下一时刻观测，使隐表示编码近端状态演化的预测信念。
- **蒸馏到通信消息**：复用同一解码器定义 $L_{aux} = \mathbb{E}\|D_\psi(\bar{m}^{(t)}_i) - o^{(t+1)}_i\|_2^2$；关键细节是**梯度只回传至通信参数，不更新解码器**，使解码器成为固定投影、定义消息的语义目标空间，防止表示塌缩为平凡编码。
- 由此形成清晰的功能分工：特权 Transformer 学预测信念表示 → 去中心化通信模块以局部观测+消息传递近似该信念 → 生成策略在完全不含特权信息的情况下消费消息。

### 2.5 总损失
- $L_{total} = L_{CFM} + \lambda_1 L_{UFM} + \lambda_2 L_{aux} + L_{intent}$，其中 $\lambda_1, \lambda_2 < 1$，辅助项只起塑形与稳定作用，主学习信号仍为 $L_{CFM}$。

### 2.6 去中心化推理与滚动时域执行
- **首步初始化**：从高斯噪声出发，以 S 次显式欧拉积分生成动作序列。
- **滚动时域热启动**：后续时刻以前一时刻预测序列 $A^{(t-1)}_i$ 为起点，以 $\alpha = 1 - 1/S$ 进行部分高斯扰动，再在 $\tau = \alpha$ 处做**单步去噪**更新。
- **执行**：仅执行第一个动作，其余作为内部计划随时间细化。每步每智能体只需**一次向量场评估**，满足实时性。
- **效果**：热启动隐式鼓励对连贯行为模式的承诺，使时序平滑性由推理过程自然涌现（无需显式平滑正则）；同时为通信中断提供原则性回退——消息不可用时继续执行先前推断的一致计划，并可选地在仅依赖最新局部观测的条件下做轻量细化。
