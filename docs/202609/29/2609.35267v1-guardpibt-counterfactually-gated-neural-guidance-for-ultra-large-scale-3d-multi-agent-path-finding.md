## 摘要
大规模三维多智能体路径规划在密集通行下变得越来越困难。带回溯的优先级继承（PIBT）具有良好的可扩展性，但在密集交互和大规模拥堵下，其单步目标导向排序可能变得不足。我们提出 GuardPIBT，它增强而非替代 PIBT 执行器：神经预测仅对 PIBT 原生候选提出残差重排序，而最终动作仍由 PIBT 决定。首先，局部图注意力对邻近交互建模，而全局源-目标输运特征为候选重排序提供群体级协调上下文。其次，反事实组门控会过滤那些闭环效应可能损害协调的重排序。第三，对于超大规模群体，群体自适应分组保持决策粒度，异步缓存推理分摊神经计算，选择性修复解决长尾智能体。PIBT 全程保留有效性检查、优先级继承和回溯。最多 100,000 个智能体的实验表明，在二维和三维环境中均能可靠完成，包括所有三次 100,000 智能体仓库运行，且经审计的图违规为零。项目网站为 {\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}。

## Abstract
Large-scale 3D multi-agent path finding becomes increasingly difficult under dense traffic. Priority Inheritance with Backtracking (PIBT) scales well, but its one-step goal-directed ordering may become insufficient under dense interactions and large-scale congestion. We present GuardPIBT, which augments rather than replaces the PIBT executor: neural predictions only propose residual reorderings of PIBT's native candidates, while final actions remain determined by PIBT. First, local graph attention models nearby interactions, while global source--goal transport features provide population-level coordination context for candidate reordering. Second, a counterfactual group gate filters reorderings whose closed-loop effects may degrade coordination. Third, for ultra-large populations, population-adaptive grouping preserves decision granularity, asynchronous cached inference amortizes neural computation, and selective repair resolves long-tail agents. PIBT retains validity checking, priority inheritance, and backtracking throughout. Experiments with up to 100,000 agents demonstrate reliable completion across 2D and 3D environments, including all three 100,000-agent warehouse runs with zero audited graph violations. The project website is available at {\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}.

## 1. 核心问题与研究动机

- **应用背景**：低空经济推动大量配送无人机、巡检平台、应急飞行器与载人 eVTOL 进入共享空域，未来城市空中交通机队规模预计达到数万架，要求协调方法能扩展到 $10^4$ 以上智能体。
- **问题场景**：三维体素空间中的多智能体路径规划（MAPF），26 连通动作（含等待共 27 个候选），障碍密集、通道受限、起讫需求动态变化。
- **现有方法瓶颈**：
  - 最优/有界次优求解器（CBS、ECBS）保证强但难以扩展；
  - LNS、滚动时域、惰性后继等方法仍依赖重复重规划；
  - PIBT 单步开销低、可扩展性好，但其**单步目标导向排序**只依赖局部交互与目标代价，难以捕捉**多智能体汇聚造成的长程拥塞**；
  - 直接引入学习偏好存在关键困难：最终执行由 PIBT 的优先级继承与回溯决定，**一个高分候选未必能改善最终联合动作**，学习偏好与闭环执行之间存在分布漂移。
- **核心主张**：不替换 PIBT，而是**增强其候选排序**，在保留经典执行器可靠性的同时引入神经引导。

## 2. 方法论

### 2.1 核心思想
- 采用**执行器对齐（executor-aligned）的神经残差框架**：网络只对 PIBT 原生 27 个候选输出残差式重排序（residual reordering），合法性检查、优先级继承、回溯、占位声明与释放全部仍由 PIBT 内核完成。
- 残差全置零时**精确退化为所选 PIBT 基线**，保证"可关断"的安全性。

### 2.2 轻量 3D PIBT 骨干
- 避免为每个目标构建完整 3D 距离场（内存 $O(NWHD)$），改用**放宽但障碍感知的下界**：
  - 共享目标柱复用一张 8 连通 BFS 场，得到投影距离 $d^{xy}_i$ 与 $d^z_i$；
  - 自由空间 26 邻域下界 $h^{\text{open}}_i$ 与投影下界 $h^{\text{proj}}_i$ 取最大值作为 $h_i(x)$。
- 候选键 $K^t_i(a) = c(a) + h_i(x^t_i + a)$，采用定点代价（轴向 100、面对角 141、体对角 173）。
- 优先级 $p^t_i = \delta^t_i + \lambda_w w^t_i + \epsilon_i$，由累积延迟与非目标等待构成。

### 2.3 全局–局部候选评分
- **局部交互分支**：13 维智能体特征（归一化位置、相对目标、时间相位、历史运动、是否在目标、度），半径图连边；两层消息感知注意力把边嵌入加到 key 和 value 上，建模最可能竞争同一目的地或处于同一继承链的邻居。
- **全局源–目标运输分支**：
  - 每个当前源–目标对定义直线路径，按宏观网格划分 token，token 存储中心、当前/目标密度、裁剪后的密度失衡、平均剩余位移、平均速度等；
  - 用 **rectified flow matching** 监督速度头（$\mathcal{L}_{FM}$），对活跃 token 做稠密自注意力；
  - 每个智能体带距离/方向/目标对齐偏置查询所有 token，得到 $z^{\text{flow}}_i$；
  - 门控残差融合 $z_i = \text{LN}(z^{\text{loc}}_i + \gamma_i \odot z^{\text{flow}}_i)$。
  - 关键点：全局上下文**在线从当前种群重建**，不是地图专属的引导图，因此可跨地图与规模迁移。
- **PIBT 感知候选评分**：候选特征 $\psi_{ia}$ 包含动作分量、目的地占用、默认需求竞争、单步反向边风险、是否为默认候选；共享网络产生 27 维 logit，可附加与运输速度的对齐项；最终编译为 $10^3(K^{\text{fix}} - \beta^{\text{fix}}) + \kappa$ 的整数分代价排序。障碍过滤在排序前完成。

### 2.4 反事实组门控
- 冻结评分器在 on-policy 帧上生成 map-valid top-k 提议，把活跃提议智能体划分到空间组；
- 对每组做**配对的 PIBT 展开**：基线与干预从同一配置、同一步级优先级噪声出发，执行真实 PIBT 内核 $H$ 步；
- 目标函数 $J(\tau)$ 综合执行代价、剩余启发、完成数、等待、运动长度、列拥塞；
- 反事实优势 $A_g = J(\tau^{\text{base}}_g) - J(\tau^{\text{int}}_g)$，标签 $y_g = \mathbb{1}[A_g > 0]$；
- 门控网络是**提议准入网络**而非策略：$\ell^{\text{cf}}_{ia} = \ell^{\text{base}}_i + w^{\top}_{\text{cf}}\tanh(W_{\text{cf}} z_i + \phi_c(\psi_{ia}))$，同状态下可接受某一候选而拒绝另一候选；
- 组内概率取均值，超过阈值 $\tau_{\text{cf}}$ 才激活该组重排序。

### 2.5 两阶段训练
- **Stage 1**：冻结无关模块，用 on-policy PIBT 展开提供状态、默认代价向量、执行有效目标候选与未来运动统计，优化排序损失、默认候选损失、流匹配损失与辅助损失。
- **Stage 2**：冻结运输编码器、局部 GAT 与候选评分器，生成组标签，仅优化反事实头，用校准与实测配对优势选择部署阈值。分离两阶段以避免标签非平稳与分布漂移。

### 2.6 超大规模部署扩展（仅 10 万级完成实验需要）
- **种群自适应分组**：按 $B_d(N)=\max(1,\text{round}[B^{\text{ref}}_d (N/N_{\text{ref}})^{1/3}])$ 缩放网格，使期望组规模近似恒定（$6\times4\times2$ @ 1000 → $28\times19\times9$ @ 100000）；组概率只用活跃提议智能体。
- **稀疏异步刷新**：全局 token 始终从全种群聚合；支持已知活跃目标模式与分块评估；单飞异步 worker 计算下一快照，PIBT 复用上一份有效残差，快照有 TTL，使神经推理分摊到多个编译 PIBT 步，不占用每步关键路径。
- **选择性长尾完成**：批量协调由分组 GuardPIBT 阶段完成；停滞时重启优先级噪声、提升未解决/被接受提议智能体、逐步放松门控、前沿保持防止已完成层被重新占据；仅最终残余集合进入时间索引 SIPP 修复，已稳定智能体作为预留，最后用短 PIBT 阶段重接回在线执行，并审计顶点、反向边、障碍与长跳违规。
- **复杂度**：一次刷新为 $O(Nk_nd + M^2d + N_tMd + 27N_td)$，目标集 $N_t \ll N$。

## 6. 主要结论与发现

- **可扩展性**：10000 智能体下，Forest 场景 $T_{E2E}$ 172.41 s vs LaGAT 386.40 s，**2.24× 加速**且 $\bar{C}_{SOC}$ 略低（241.33 vs 249.77）；Maze 场景相对 LaCAM 从 174.89 s 降至 113.53 s（1.54× 加速），$\bar{C}_{SOC}$ 从 2910.90 降至 2051.33（**降低 29.5%**）。
- **非全面占优**：小规模（100）时因推理与协调开销反而慢于轻量搜索方法，但 $\bar{C}_{SOC}$ 最低；10000 智能体 Warehouse 场景 LaCAM 更快、LaGAT 代价更低，说明其优势在于**效率与解质量的权衡**而非单一指标最优。
- **10 万级完成能力**：Gate-Walls-3D 194.61 s、Warehouse-3D 908.61 s、Forest-2D 1104.83 s、Warehouse-2D 1163.11 s、Maze-2D 5208.15 s，全部完成；三次 10 万仓库运行**审计图违规为零**。
- **百万级验证**：100 万智能体 3D 实例全部到达目标，无顶点/交换/障碍冲突，$T_{E2E}$ 约 995 s。
- **消融结论**：
  - 去掉全局 flow 分支：SOC 由 3739.17 升至 4089.50，等待步数 2192.83→2521.93，等待率 58.52%→61.54%，说明群体级运输上下文能减少低效运动与长等待；
  - 去掉反事实门控：SOC 升至 3772.39、等待步数 2205.99，$T_{E2E}$ 与等待率接近完整模型，说明门控主要提升**候选干预质量**而非降低计算量；
  - 三变体 $T_{E2E}$ 差异小，说明两组件均非以加速为首要目标。

## 7. 优点

- **架构设计克制**：不替换 PIBT，只做候选排序残差，且残差归零可精确退化，保留了经典执行器的可验证性与安全性，工程上易于回退。
- **执行器对齐的监督范式**：用配对基线/干预 PIBT 展开的闭环反事实优势做组级标签，直接度量"排序改动是否真的改善最终联合执行"，规避了"高分候选≠更好执行"的错配，是本文最有价值的思路。
- **全局表征可迁移**：全局运输 token 在线从当前种群重建、固定在通用 3D 网格上，而非地图专属引导图，因此支持跨地图、跨规模、跨维度泛化。
- **两阶段训练解耦**：先学提议、再学准入，避免反事实标签非平稳，同时冻结部分模块降低训练耦合。
- **超大规模工程方案完整**：种群自适应分组、异步缓存推理、单飞 worker、TTL 过期、长尾 SIPP 修复、最终违规审计，构成一套从算法到部署的闭环。
- **评测较诚实**：主动指出自身在小规模和 Warehouse 场景不占优，并在消融中强调"所有变体都完成"以避免用失败掩盖低代价。

- **应用限制**：
  - 仅面向离散时间、离散体

- 仅面向**离散时间、离散体素化的 3D 网格**，动作空间固定为 26 邻域 + 等待；对连续空间、非结构化空域、动态障碍（如移动禁飞区、临时管制）以及有人机混合运行的适应性未做验证。
- 全局运输 token 依赖**当前种群的源–目标统计**，若部署时的需求分布与训练分布差异较大（例如极端偏斜或目标高度重叠），flow 头与门控阈值可能需要重新校准；文中未给出这种分布漂移下的敏感性分析。
- 反事实门控阈值的选取依赖**实测配对优势**，部署阶段若无法获得同类 on-policy 展开数据，阈值迁移的可信度缺乏保证。
- 长尾 SIPP 修复阶段与在线执行的重接过程，其正确性仅在报告场景中通过审计检查确认，**未提供形式化的安全性证明**（如无碰撞不变式、活性保证）。

## 9. 启示与可拓展方向

- **执行器对齐监督可推广**：把"候选排序改变是否真正改善闭环执行"作为学习目标的思路，不局限于 PIBT，也可用于其他优先级继承/回溯式求解器（如某些贪心 MAPF、滚动时域规划器）的偏好学习。
- **在线重建的全局表征**是解决"学习引导图不可迁移"的一条可行路径：把群体级统计压缩为可查询 token，而非把地图信息编码进网络，天然支持跨地图与跨规模。
- **分层部署范式**：批量协调 + 异步神经刷新 + 长尾精确修复 + 最终审计的组合，对 10 万级以上的大规模调度问题具有参考价值，其工程权衡（TTL、单飞 worker、分组缩放律）可能比算法本身更可复用。
- 值得进一步研究的方向：把门控阈值学习为在线自适应量；将 26 邻域扩展为任意动作集；引入动态/对抗性环境；以及在同等算力下与最新学习型 PIBT 方法做受控对比。

## 10. 总体评价

GuardPIBT 的定位清晰且克制：它不试图用神经网络替代经典 MAPF 执行器，而是以**残差式候选重排序 + 反事实组门控**的方式，在保留 PIBT 可验证性的同时补足其长程拥塞感知能力。其最具贡献的两点是（i）**执行器对齐的反事实监督**，直接以闭环执行质量为标签，绕开了"高分候选 ≠ 更好联合动作"的错配；（ii）**在线重建的全局运输表征**，使模型能够跨地图、跨规模、跨维度迁移，并在 10 万乃至 100 万智能体规模上给出可运行结果。

但论文也存在明显的证据边界：训练成本与参数量披露不足、大规模实验重复次数有限、百万级仅单场景单次运行、部分基线关键配置缺失、小规模与仓库场景并不占优、完成性依赖启发式修复而非形式化保证。因此更恰当的结论是：GuardPIBT 在**超大规模、障碍密集、2D/3D 混合**的批量 MAPF 场景中展示了"效率–质量–规模"三者之间一条有竞争力的折中路径，而非一个全面支配既有方法的通用最优解。其方法论价值（执行器对齐学习 + 在线全局表征 + 分层部署）可能比具体数值结果更具长期参考意义。
